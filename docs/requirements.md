## 1 项目概述

### 1.1 背景

中高端月子中心普遍存在四类问题：房态靠 Excel 手工排、护理记录纸笔交接易漏项、客户从留资到签约链路断在微信里、多门店（多品牌）数据混在一起无法独立核算。本项目建设一套 **SaaS 多租户平台**，一套系统同时服务多个门店/品牌，数据物理隔离、独立配置、独立计费。

### 1.2 建设范围

| 端 | 使用者 | 主要用途 |
|---|---|---|
| 平台管理端 | 平台运营方 | 租户开通/停用/续期、套餐与配额、账单、平台审计 |
| 租户后台 | 门店店长、销售、护理主管、护士、营养师、康复师、财务、市场 | 房态、CRM、订单、在住、护理、康复、月子餐、员工、会员、内容、报表、系统设置 |
| PC 官网 | 潜在客户 | 品牌展示、房型套餐、案例、留资预约、SEO 获客 |
| 微信公众号 | 粉丝/客户 | 内容触达、菜单入口、粉丝与标签、自动回复 |
| 客户小程序 | 在住/意向客户 | 浏览下单、支付定金、订单进度、护理摘要、月子餐、康复预约、积分与券 |
| 护理师小程序 | 护理员 | 今日任务、护理执行、交接班、异常上报、出餐核对、考勤 |
| H5 | 分享落地客户 | 活动/案例分享、预约参观、支付回跳、轻量订单查询 |
| App | 高价值客户 | 同小程序能力 + 推送 + 离线缓存 |

### 1.3 不在本期范围

- 自建支付通道（使用微信支付 v3 商户号）
- 电子发票、财务总账（仅做收款与对账记录）
- 视频监控与智能硬件对接（预留接口）
- 多语言内容的人工翻译服务（系统只提供多语言能力）

## 2 角色与权限

### 2.1 角色矩阵

| 角色 | 数据范围 | 关键权限 | 禁止权限 |
|---|---|---|---|
| 平台超管 | 全平台 | 租户全生命周期、套餐、账单、平台账号 | 不得进入租户业务数据 |
| 平台运营 | 全平台 | 租户查看、续期、工单 | 不得删除租户、不得改套餐价格 |
| 平台财务 | 全平台 | 账单生成、标记支付、导出 | 不得操作租户业务 |
| 店长 | 本租户 | 全部业务 + 员工 + 报表 + 参数 | 不得跨租户 |
| 销售顾问 | 本租户 | 线索、参观、订单、合同 | 不得看护理记录明细、不得改价格策略 |
| 护理主管 | 本租户 | 护理计划、记录审批、交接、异常闭环、排班 | 不得看订单金额与支付 |
| 护理师 | 本租户 | 本人任务执行、记录补录、异常上报 | 不得改计划、不得看价格 |
| 营养师 | 本租户 | 餐单模板、忌口、加餐 | 不得看订单金额 |
| 康复师 | 本租户 | 评估、疗程卡、预约排程、执行扣次 | 不得看订单金额 |
| 财务 | 本租户 | 收款、退款审核、对账、报表 | 不得改护理与房态 |
| 市场 | 本租户 | 内容、活动、优惠券、渠道码 | 不得看客户手机号明文 |
| 客户（C 端） | 本人 | 本人订单、护理、餐食、康复、积分 | 不得看他人任何数据 |

### 2.2 权限模型

- RBAC：用户 → 角色 → 菜单/按钮 → 接口；接口层再做 `AuthGuard` 与租户上下文双重校验。
- 越权返回固定错误码：跨租户 `40300`、无权限 `40304`、平台/租户入口混用 `40305`，便于验收脚本断言。

## 4 非功能需求

| 类别 | 指标 |
|---|---|
| 性能 | 列表接口 P95 < 500ms（万级数据）；下单接口 P95 < 800ms；并发抢房不超卖 |
| 并发 | 单租户 200 并发浏览、20 并发下单；平台 500 并发 |
| 可用性 | 年可用性 ≥ 99.5%；数据库每日全量备份保留 14 天 |
| 安全 | 手机号/证件/密钥 AES-GCM 加密；展示脱敏；越权固定错误码；写操作审计；接口限流与幂等 |
| 兼容 | 后台 Chrome/Edge 最新两个版本；小程序基础库 ≥ 2.30；H5 iOS 14+/Android 10+；App Android 8+/iOS 14+ |
| 多语言 | 中英双语，语言包可扩展，缺失词条回落默认语言 |
| 可维护 | 18 个 Maven 模块按域拆分；前端通用列表组件；接口文档 OpenAPI 自动生成 |

## 6 验收标准

1. **功能验收**：`tasks.md` 每项有可演示入口或可调用接口；关键流程（下单→支付→入馆→护理→出馆结算）端到端跑通。
2. **隔离验收**：`deploy/test-isolation.sh` 全部通过（双租户互不可见、跨租户 403/404）。
3. **安全验收**：`deploy/test-security.sh` 全部通过（401/403、敏感词、幂等、限流、路径穿越、脱敏、审计）。
4. **多端验收**：`deploy/smoke-mobile.sh` 全部通过；官网/后台/H5 可构建并访问。
5. **多语言验收**：`deploy/test-i18n.sh` 全部通过。
6. **工程验收**：`mvn -DskipTests compile`、`mvn test`、`npm run build`（admin-web / web-site / h5）、`flutter analyze` 均无错误。
