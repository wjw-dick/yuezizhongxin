## 1 总体架构

### 1.1 架构选型

采用 **模块化单体 + 多租户 SaaS**：按业务域拆 18 个 Maven 模块，单进程部署，模块间只能通过 Service 接口调用，禁止跨模块直接访问对方 Mapper。理由：

- 月子中心业务事务强（下单要同时锁房、写订单、冻结库存），分布式事务成本高于收益；
- 单租户数据量级（房间数百、订单数千/年）不需要分库分表；
- 模块边界清晰，后续任一域（如护理、康复）可独立拆服务。

### 1.2 技术栈

| 层 | 选型 |
|---|---|
| 后端 | Java 17、Spring Boot 3.2、MyBatis-Plus 3.5（租户行级插件）、MySQL 8、Redis、RabbitMQ |
| 前端后台 | Vue 3 + Vite 5 + TypeScript + Element Plus 2.8 + WangEditor 5 |
| 官网 | Vue 3 + vue-router（history）+ axios，SSR 无关的静态化 SEO 方案 |
| 小程序 | 微信原生（客户端 / 护理师端两套独立工程） |
| H5 | Vue 3 + Vite，hash 路由，适配微信内分享 |
| App | Flutter 3（Android / iOS 一套代码） |
| 部署 | Docker Compose、Nginx、Prometheus + Grafana |

### 1.3 多租户实现

```
请求 → TenantContextFilter（X-Tenant-Code / 子域名 / 令牌）
     → AuthInterceptor（登录态 + 平台/租户入口隔离）
     → TenantLineInnerInterceptor（SQL 自动追加 tenant_id）
     → Service 内 AuthGuard.requireTenant() 兜底
```

- 租户标识只信任服务端解析结果，前端单独传的 `tenantCode` 不作为授权依据；
- 所有业务表带 `tenant_id` 且参与唯一键（如 `(tenant_id, room_id, biz_date)`），从数据库层面杜绝跨租户串号；
- 跨租户访问固定返回 `40300`，按主键越权返回 `40400`，便于自动化验收。

### 1.4 高并发抢房

下单锁档采用 **唯一键 + 条件更新** 双保险：

1. `room_schedule` 对 `(tenant_id, room_id, biz_date)` 建唯一索引；
2. 插入冲突捕获 `DuplicateKeyException` → 返回 `40901`，前端提示换日期/房型；
3. 锁定 60 分钟未支付自动释放（定时任务扫描），取消与退订立即释放；
4. 库存类商品用 `update ... where stock >= n` 条件更新，避免超卖。

## 2 功能实现要点

| 模块 | 关键实现 |
|---|---|
| 平台端 | 租户开通在单事务内建租户 + 9 角色 + 14 菜单 + 12 参数，秒级完成；五态拦截在过滤器层 |
| 订单 | 状态机集中在 `OrderService`，所有状态变更走同一入口并写审计；金额四舍五入统一 `HALF_UP` |
| 护理 | 计划项与记录分离；记录写服务端时间，超 24 小时补录置「待审批」且不计完成率 |
| 康复 | 预约冲突双维度校验（治疗师、康复室），客户自助预约落「待确认」由门店指派 |
| 月子餐 | 模板按阶段生成，出餐核对与加餐计费同表，出馆结算自动汇总 |
| 会员 | UnionID 统一多端身份；积分/储值变动必写流水；储值前强制展示预付卡规则 |
| 公众号 | access_token 缓存 7000 秒；未配凭证时统计走本地降级并在 UI 明示 |
| 导出 | 服务端生成 SpreadsheetML/HTML 表格，带水印、用途必填、5000 行上限、操作留痕 |

## 3 安全设计

| 风险 | 措施 |
|---|---|
| 数据泄露 | 手机号/证件/密钥 AES-GCM 加密落库；接口一律脱敏；密钥不落日志 |
| 越权 | 令牌内嵌租户，服务端校验；按主键再校验归属；错误码可断言 |
| 重复提交 | `@Idempotent` + `X-Idempotent-Key`，覆盖留资、下单、护理执行 |
| 刷验证码 | 同号 60 秒一条、每小时 10 条，Redis 计数 |
| 上传攻击 | 文件名净化、对象键必须 `tenants/{code}/` 前缀，`..` 直接拒绝 |
| 内容风险 | 标题/正文敏感词校验（`SensitiveWordFilter.assertClean`），命中返回 `40010` |
| 审计 | 所有写操作 `@AuditLog` 落库，含模块、动作、操作人、前后值摘要 |

## 4 部署方案

```
                     ┌──────────── Nginx (443) ────────────┐
 www → 官网静态       │ admin → 后台静态   m → H5 静态      │
 api → /api 反代 ─────┴──────────────┬──────────────────────┘
                                     ▼
                         backend (Spring Boot, 8080)
                    ┌────────┬────────┴────────┬──────────┐
                 MySQL8    Redis7          RabbitMQ    MinIO
                    └────────┴────────┬────────┴──────────┘
                              backup（每日 02:30 全量）
                              prometheus + grafana（监控）
```

- 数据库与对象存储不对外暴露端口；
- 备份保留 14 天并做可解压自检；
- 健康检查 `/actuator/health`，指标 `/actuator/prometheus`。
