# 月子中心数字化运营平台 · 用户使用手册

> 适用版本 v1.0　读者：平台运营、门店店长与各岗位员工、客户（C 端）
> 约定：`【路径】` 表示后台左侧菜单，`→` 表示点击顺序，`{}` 表示需替换的内容。

---

## 1 快速开始

### 1.1 入口一览

| 入口 | 地址 | 账号来源 |
|---|---|---|
| 平台管理端 | `https://admin.{域名}/#/platform/tenants` | 平台运营分配 |
| 租户后台 | `https://admin.{域名}/` | 门店开通时生成的管理员账号 |
| PC 官网 | `https://www.{域名}` | 无需登录 |
| H5 | `https://m.{域名}/h5/` | 无需登录，可登录会员 |
| 客户小程序 | 微信搜索或扫门店码 | 手机号验证码登录 |
| 护理师小程序 | 门店内部二维码 | 员工账号（由主管绑定） |

### 1.2 首次登录（租户后台）

1. 打开 `https://admin.{域名}/`，输入门店编码（如 `demo`）、账号、初始密码。
2. 首次登录强制修改密码（长度 ≥ 8，含字母与数字）。
3. 进入 `【概览】` → 工作台，确认 8 类提醒卡片有数据。
4. 若提示「租户已停用/已到期」，联系平台运营续期。

### 1.3 角色与可见菜单

| 角色 | 可见菜单（摘要） |
|---|---|
| 店长 | 全部 |
| 销售顾问 | 概览、房态、房型、套餐、CRM、订单、会员、内容 |
| 护理主管 | 概览、在住、护理、康复、月子餐、员工 |
| 护理师 | 用护理师小程序；后台仅查看在住与护理 |
| 营养师 | 月子餐、在住（只读） |
| 康复师 | 康复、在住（只读） |
| 财务 | 订单（收款/退款/对账）、报表 |
| 市场 | 内容、会员、公众号、报表（渠道） |

> 菜单由角色决定，看不到某菜单说明当前角色无权限，请联系店长调整。

## 2 平台运营操作

### 2.1 开通门店（租户）

1. `【平台】→ 租户管理` → 右上角「开通门店」。
2. 填写：门店编码（英文小写+数字，唯一）、门店名称、行业、联系人、电话、套餐、试用天数、管理员账号与姓名。
3. 提交后系统自动完成：建租户 → 建 9 个角色 → 建 14 个菜单及授权 → 写入 12 项参数 → 生成管理员初始密码。
4. 弹窗复制「初始密码」交给门店，**关闭后不再显示**，遗忘需重置。

### 2.2 停用 / 恢复 / 续期

1. `【平台】→ 租户管理`，在目标门店行点「停用」：立即禁止登录，已登录会话下次请求失效。
2. 「恢复」后门店可正常登录，数据不丢失。
3. 「续期」填写到期日，系统按新日期重新计算状态（到期前 15 天开始提醒）。

### 2.3 套餐与账单

1. `【平台】→ 套餐管理`：维护房间数、员工数、存储、短信、门店数五类配额。
2. `【平台】→ 账单`：点「生成本月账单」按席位计费 → 收款后「标记已支付」。
3. 逾期未支付的门店会被标记欠费，写操作受限（仍可登录查看）。

## 3 门店日常（租户后台）

### 3.1 基础配置（一次性）

1. `【系统设置】→ 参数配置`：门店名称、电话、地址、ICP、公众号名称。
2. `【系统设置】→ 字典管理`：房型档位、护理模式、流失原因、忌口类型等。
3. `【系统设置】→ 角色权限`：按岗位勾选菜单（左侧选角色，右侧勾权限，保存授权）。
4. `【系统设置】→ 入口管理`：生成小程序码、App 下载码，填渠道码后可统计来源。

### 3.2 房型与房间

1. `【房型管理】` → 新增房型：名称、档位、面积、床型、可住人数、设施、上传图集、富文本介绍。
2. `【房态日历】` → 切换楼层，查看每月占用；点某房某日可看该订单。
3. 房间维修：`【房型管理】→ 房间`，把状态改为「维修」，房态日历置灰不可下单。

### 3.3 套餐与商品

1. `【套餐管理】` → 新增：名称、天数、价格、定金比例、配套房型档位、护理模式、含康复项目。
2. 上架后官网/小程序立刻可见；下架后不影响已成交订单。
3. `【商品与增值】` 维护加餐、康复加购、母婴用品，设置库存与上下架。

### 3.4 线索到签约（销售）

1. `【CRM 客户】` 默认看板视图，五个泳道：待联系 → 已联系 → 已参观 → 已签约 → 已流失。
2. 新增线索：称呼、手机号、预产期、意向房型、来源渠道、下次跟进时间。
3. 点卡片进详情 → 「添加跟进」写沟通记录；「推进阶段」变更泳道。
4. 客户到店：详情 → 「预约参观」填日期时段 → 到店后「签到」。
5. 签约：详情 → 「转订单」，选择套餐与入馆日期，系统按套餐天数自动算离馆日，生成订单。
6. 客户不来了：详情 → 「标记流失」，**流失原因必选**（用于渠道分析）。

> 「跟进超时」标签页会汇总所有超过下次跟进时间的线索，按红黄分级。

### 3.5 订单与收款（销售 / 财务）

1. `【订单管理】` 三个标签页：订单列表、退款审核、待对账。
2. 收款：订单行「收款」→ 选类型（定金/尾款/增值）与方式（微信/现金/转账）→ 提交即生成流水，订单状态自动推进。
3. 微信支付：客户在小程序/App 自助支付，回调自动入账，无需人工操作。
4. 退订：客户申请后进入「退款审核」→ 审核通过并填退款金额 → 原路退回 → 系统释放档期。
5. 变更：订单详情「变更」→ 换房（校验新房间档期）/ 延期（自动补差价）/ 改套餐。
6. 待对账：按支付方式汇总当日收款，与收款平台逐笔核对后「标记对账」。

### 3.6 入馆办理（前台 / 护理主管）

1. `【在住管理】→ 待入馆`，找到今日到店客户 → 「办理入馆」。
2. 核对房间、护理模式、陪护人数；上传证件（加密存储，仅显示掩码）。
3. 勾选健康告知（未勾选无法提交）；确认护理天数。
4. 提交后订单转「在住」，护理计划自动生成，客户小程序立刻可看。

### 3.7 护理执行（护理师）

**用护理师小程序**（推荐）：

1. 登录 → 工作台，看今日任务、完成率、待处置异常、待核对出餐。
2. 上下班打卡（需定位授权）。
3. 点任务 → 录体温/体重/血压/脉搏/喂养量/黄疸/大小便与记录内容 → 提交。
4. 提交后客户小程序即时可见，后台看板完成率同步。

**用后台**（主管补录/审批）：

1. `【护理管理】→ 计划`：按日期分组查看计划项，可增删单项、指定护理员。
2. `【护理管理】→ 记录`：修改记录（24 小时内直接改并留痕）；超 24 小时补录须填原因，进入「待审批」。
3. `【护理管理】→ 交接班`：新建交接单（重点观察必填）→ 接班人「接班确认」。
4. `【护理管理】→ 异常`：上报异常（类型/紧急度/描述/照片）→ 主管处置 → 闭环并记录家属告知。

### 3.8 月子餐（营养师）

1. `【月子餐】→ 阶段模板`：按排/调/补/养四阶段维护早中晚加餐组合。
2. 「一键排餐」按在住订单生成当日餐单（自动带房间与份数）。
3. `【月子餐】→ 出餐核对`：按房间查看份数与特殊标记（忌口/过敏/加餐），逐份核对，异常必填说明。
4. 客户在小程序登记忌口后，出餐明细自动带标记。

### 3.9 康复（康复师）

1. `【康复】→ 项目库`：名称、阶段、时长、标准次数、价格、资质要求。
2. `【康复】→ 评估`：录入盆底肌评分、腹直肌分离、体态、情绪与报告。
3. `【康复】→ 疗程卡`：查看客户剩余次数、到期日。
4. `【康复】→ 预约排程`：选日期，指派治疗师与康复室；冲突会提示（同治疗师或同房间同时段）。
5. 客户在小程序自助预约后状态为「待确认」，需在排程页确认并指派治疗师。
6. `【康复】→ 执行记录`：完成后「执行扣次」，剩余次数自动减 1。

### 3.10 出馆结算（前台 / 财务）

1. `【在住管理】→ 在住` → 客户卡片「出馆结算」。
2. 核对尾款、增值服务、加餐费用；录入押金退还方式。
3. 勾选物品归还、填满意度、预约 42 天复查、写护理小结。
4. 提交后订单转「待结算」；收齐尾款后转「已完成」。

### 3.11 员工与排班（店长）

1. `【员工管理】→ 档案`：新增员工（岗位、电话、是否在职），并绑定登录账号（护理师小程序必需）。
2. `【员工管理】→ 资质证件`：录证件与有效期，60 天内到期在「预警」标签提示。
3. `【员工管理】→ 班次 / 排班`：定义白班夜班，周排班矩阵按列拖选；一对一护理配比不足会拦截保存。
4. `【员工管理】→ 考勤 / 工作量`：查看打卡与班次完成情况。

### 3.12 会员与营销（市场）

1. `【会员管理】→ 档案`：查看会员资产与标签；点「详情」看积分流水、持券、储值记录。
2. `【会员管理】→ 标签`：新增标签并给会员打标；「分群触达」按标签圈人，同人同内容 24 小时只发一次。
3. `【会员管理】→ 优惠券模板`：面额、门槛、发行量、有效期；发出后客户端可领。
4. `【会员管理】→ 活动`：活动名称、时间、规则，到点自动上下线。
5. `【会员管理】→ 转介绍`：查看推荐记录，「结算」把积分发给推荐人。

### 3.13 内容与官网（市场）

1. `【内容管理】` → 新增：选类型（文章/案例/活动/团队）、填标题与富文本、上传封面。
2. **适用端多选必选**（官网/小程序/H5/公众号），发布后只在所选端出现。
3. 案例类内容必须打开「客户授权」开关，否则不允许发布。
4. 填 SEO 标题/关键词/描述；中英双语在「多语言」页签分别填写。
5. 操作：保存草稿 → 保存并发布 → 需要下架时「下线」。

### 3.14 公众号（市场）

1. `【公众号】→ 账号台账`：填 AppID、AppSecret、Token、EncodingAESKey（保存后只显示掩码）。
2. 复制「服务器地址」与「Token」到微信公众平台「服务器配置」，并在微信后台加 IP 白名单。
3. 凭证未完善时其余子页按钮置灰，属正常保护。
4. 菜单：三级结构编辑，右侧手机预览，保存并发布；清空需二次确认。
5. 自动回复：关注时、收到消息、关键词三类，关键词支持全匹配/半匹配。
6. 统计：用户增长、消息、图文阅读；若显示「本地降级数据」，说明该账号未授权或接口受限。

### 3.15 报表与导出（店长 / 财务）

1. `【报表】` 五个标签：日报、月报、护理、餐食、人力。
2. 指标卡看当期核心数据，趋势图看环比。
3. 导出：选模块与时间范围，**用途必填**，超过 5000 行请缩小范围；导出文件带水印并留操作记录。

## 4 客户端使用（客户）

### 4.1 小程序

| 步骤 | 操作 |
|---|---|
| 1 | 微信搜索门店小程序或扫门店码进入 |
| 2 | 首页看套餐与房型，「预约参观」填称呼、手机号、预产期、到店时间 |
| 3 | 选套餐 → 「立即预订」→ 选入住日期（自动算离馆日）→ 填姓名手机 → 提交 |
| 4 | 支付定金（未开通在线支付时提示到店支付）→ 结果页保留订单号 |
| 5 | `订单` 页看状态、支付进度、合同；待支付可重新发起支付 |
| 6 | 入馆后 `我的 → 护理记录` 看每日护理项、体征趋势，可「每日护理确认」 |
| 7 | `我的 → 康复与月子餐` 看疗程余额、预约康复、看今日餐单、登记忌口、申请加餐 |
| 8 | `我的` 页看积分、储值、优惠券，可领券、储值（需先看预付卡规则）、转介绍 |

### 4.2 H5

- 分享链接打开即为落地页，可预约参观；`#/orders` 用订单号+手机号查进度。
- 支付完成后回到 `#/pay/result`，显示成功/取消与订单号。

### 4.3 App

- 首次打开用手机号验证码登录；首页看套餐与在住概览。
- `订单` 页支持下拉刷新，弱网显示离线缓存并提示「当前为离线缓存数据」。
- `我的 → 护理日志` 看计划完成率与护理记录；`消息通知` 汇总最新护理动态。

## 5 护理师小程序

| 步骤 | 操作 |
|---|---|
| 1 | 输入门店编码、账号、密码登录（账号需在后台员工档案绑定） |
| 2 | 工作台看今日任务、完成率、负责客户数、待处置异常 |
| 3 | 点击「上班打卡」（需定位，失败可选「定位未授权」由主管核对） |
| 4 | 点任务 → 录体征与记录 → 提交（重复提交会被拦截） |
| 5 | `交接班` 新建交接单，重点观察必填；接班时「接班确认」 |
| 6 | `异常` 上报：选客户、类型、紧急度、描述；紧急项会置顶提醒 |
| 7 | `出餐` 按房间核对，异常需填说明 |
| 8 | `我的` 看本月考勤与档案，退出登录 |

> 护理师端**不显示任何价格与支付信息**，客户手机号仅显示必要字段。

## 6 常见问题

| 问题 | 处理 |
|---|---|
| 登录提示「账号或密码错误」 | 确认门店编码是否正确；连续 5 次失败会临时锁定，等 5 分钟或让店长重置 |
| 提示「无权访问其他租户的数据」 | 浏览器开了多个后台标签，退出后重新登录当前门店 |
| 提示「该房间该日期档期已被占用」 | 换房或换日期；房态日历可看具体占用 |
| 下单提示「请勿重复提交」 | 10~30 秒内重复点击被幂等拦截，稍后再试 |
| 小程序支付失败 | 检查是否开通商户号；未开通时选到店支付，档期保留 24 小时 |
| 客户看不到护理记录 | 确认订单已「办理入馆」且护理计划已生成；护理师提交后需刷新 |
| 出餐核对没数据 | 营养师未「一键排餐」，或客户未处于在住状态 |
| 康复预约提示冲突 | 换时段，或换治疗师/康复室；冲突由系统强制校验 |
| 导出文件打不开 | 导出为 `.xls`（SpreadsheetML），用 Excel/WPS 打开；过大请缩小范围 |
| 公众号统计显示「本地降级数据」 | 凭证未完善或 IP 未加白名单，配好后重新拉取 |
